# Dashboard Analytic

This repository follows a Spec‑Driven Development (SDD) workflow with multiple stages.

## Stage 0 – Foundations
* Constitution, requirements, architecture, API contract, validation.

## Stage 1 – Scaffold
* Front‑end (Next.js), back‑end (FastAPI), Docker‑Compose, deployment, testing specs.

## Stage 2 – Sample Data & Scaffold Implementation
* Added `data/sample_data.csv` containing example analytics data.
* Scaffolded a minimal Next.js 15 front‑end and FastAPI back‑end with Dockerfiles.
* Created `docker-compose.yml` and `nginx.conf` to run the services together.
* Updated specifications to reflect the new implementation stage (see `specs/stage2/`).

Further stages will expand functionality, add analytics endpoints, and improve UI/UX.
