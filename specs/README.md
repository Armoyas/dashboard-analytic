# Specification Overview

This repository follows a **Spec‑Driven Development (SDD)** workflow. Each development stage has its own folder under `specs/` containing the relevant documentation.

## Stages

- **stage0** – Foundation specifications (constitution, requirements, architecture, API contract, validation). 
- **stage1** – Scaffold specifications (frontend, backend, deployment, testing, validation). 
- **stage2** – Implementation specifications (sample data, initial front‑end/backend scaffolding, Docker setup, updated README files).

> Each stage’s `README.md` provides a quick summary of the deliverables and points to the detailed spec files within the same folder.
