# Stage 0 – Foundation Specifications

This folder contains the foundational documents for the **Dashboard Analytic** project:

- `constitution.md` – Project principles and governance.
- `requirements.md` – High‑level functional and non‑functional requirements.
- `architecture.md` – System architecture overview.
- `api-contract.md` – Initial API contract definitions.
- `validation.md` – Validation checklist for the foundation stage.

**Status:** Completed and merged into `main`.

---

> **Note:** Subsequent stages build on these foundations. Stage 2 (implementation) adds sample data, a minimal front‑end/back‑end scaffold, and Docker orchestration. See `specs/stage2/` for details.
